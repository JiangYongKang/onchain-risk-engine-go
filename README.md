# onchain-risk-engine-go

本地交易图风险分析与交易模拟引擎：用本地账本数据模拟链上资金流，
在重复、乱序和异常输入下给出稳定且可解释的风险结论。

## 模块结构

| 包 | 职责 |
|---|---|
| `ledger` | 原始记录摄取、规范化、幂等存储 |
| `graph`  | 交易图构建、模式识别、风险评分 |
| `rules`  | 版本化规则集、分析引擎、规则回放 |
| `sim`    | 账户余额重放与交易试算模拟 |

## 数据模型

**`ledger.RawRecord`（`map[string]any`）表示未规范化的外部投递，必填字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `tx_id` | string | 交易 ID（≤128 字符，不含空白） |
| `from` / `to` | string | 转出 / 转入账户 |
| `amount` | int64 | 金额（最小单位整数，必须 > 0；JSON 整数值 float64 可容忍） |
| `tx_time` | int64 | 交易时间（≥ 0） |

规范化后为 `ledger.Transfer`。金额为整数而非最小单位，避免浮点不确定性。

## 摄取语义（ledger）

- **幂等**：以 `tx_id` 为键。相同内容重复投递返回 `duplicate`，状态不变；
  同 ID 不同内容返回 `rejected/invalid_id`（冲突拒绝）。
- **拒绝原因可区分**：`missing_field`（字段缺失）、`invalid_type`（类型非法）、
  `invalid_amount`（金额 ≤ 0）、`invalid_id`（ID 非法或冲突）。
  任何被拒绝或重复的记录都不改变账本状态，且都有显式结果返回，不被静默忽略。
- **乱序安全**：`Snapshot()` 按 `tx_id` 排序输出；建图时再按 `(tx_time, tx_id)`
  排序，因此摄取顺序不影响最终图结构与分析结论。

## 风险判定规则（graph + rules）

在交易图（账户为节点、转账为有向边）上识别四类模式，每条发现（`Finding`）
都附带可核对的判定依据（涉及账户、金额、阈值阈值）：

| 模式 | 判定条件（默认阈值） | 权重 |
|---|---|---|
| `fan_in` 资金汇聚 | 单账户不同来源数 ≥ 3 | 20 |
| `fan_out` 资金拆分 | 单账户不同去向数 ≥ 3 | 20 |
| `cycle` 资金环路 | 强连通分量大小 > 1（或自环），环内流水 ≥ 1 | 40 |
| `concentration` 异常集中 | 单账户流入占总流水 ≥ 50% | 30 |

**评分公式**：`score = Σ weight(kind)`（每条 finding 计一次）。
等级映射：`<30 low`，`30–59 medium`，`60–99 high`，`≥100 critical`。

环路检测使用**迭代式 Tarjan SCC**（显式栈），10 万级深链、5 万节点大环
均可安全完成，不会爆栈或挂起；`MaxNodes` 提供图规模上限保护，
超限时跳过环扫描并输出明确的安全保护说明，而非错误结论。

## 并发与一致性保证

- `Ledger`、`Replayer`、`Simulator` 内部均以互斥锁保护，测试经 `-race` 验证。
- `Engine.Analyze` 是纯函数（输入快照 → 报告），不读写共享状态，
  可安全并发调用；测试以 32 个并发分析验证结论逐字节一致。
- 确定性来源：快照排序、建图排序、finding 排序、账户列表排序，
  全链路无 map 迭代顺序泄漏。

## 规则更新与回放（rules.Replayer）

- 规则集带严格递增的版本号，`UpdateRules` 拒绝非递增版本。
- `Run` 用当前规则出结论并追加到历史；`Replay(version, input)` 用任意
  历史版本重新分析同一输入，结果可复现，且回放结论同样入历史。
- 历史只追加不覆盖，旧结论始终可追溯。

## 交易模拟（sim）

- `Apply()` 把账本快照确定性重放到账户余额，可重复调用结果一致。
- `Simulate(rawRecord)` 在快照副本上试算一笔新交易：返回摄取结果、
  试算后的账户状态与当前规则下的风险结论，**不改变**真实账本与账户。

## 本地验证

```bash
go build ./...        # 编译
go test ./...         # 全部单测
go test -race ./...   # 竞态检测
go test -v ./graph/   # 查看输入、判定依据与结论日志
```

测试覆盖：重复与乱序摄取、拒绝原因区分、并发分析一致性、
超深链路 / 大环 / 自环、规则更新与回放、模拟无副作用。
单测日志（`-v`）会打印输入记录、每条 finding 的判定依据与最终评分结论。
